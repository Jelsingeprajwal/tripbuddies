# TripBuddies 🌍

TripBuddies is a modern travel companion platform built with **Next.js** that helps travelers discover trips, connect with like-minded people, and plan memorable journeys together.

## ✨ Features

- 🗺️ **Explore Trips** — Discover upcoming trips and travel destinations.
- 👥 **Find Travel Buddies** — Connect with people who share similar travel interests.
- 🧳 **Create Trips** — Plan and publish your own trips.
- 🔎 **Search & Filter** — Find trips based on destination, dates, interests, and preferences.
- 👤 **User Profiles** — Create a profile and showcase your travel interests.
- 💬 **Social Interaction** — Connect and communicate with fellow travelers.
- 📱 **Responsive Design** — Optimized for desktop, tablet, and mobile devices.
- 🔐 **Authentication** — Secure user authentication and protected features.

## 🛠️ Tech Stack

- **Framework:** Next.js
- **Language:** TypeScript
- **UI:** React
- **Styling:** Tailwind CSS
- **Database:** PostgreSQL
- **Authentication:** Your Auth Provider
- **ORM:** Prisma
- **Deployment:** Vercel
